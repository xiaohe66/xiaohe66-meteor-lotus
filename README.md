Lotus 是一个 [Meteor Client](https://meteorclient.com/) 的客户端插件，基于 Fabric，面向 Minecraft 无政府（anarchy）服务器的生存与挂机场景，提供一批自动化、挂机辅助和 HUD 显示增强功能。

- 纯客户端插件，基于 Fabric
- 依赖 Meteor Client，不修改服务端
- 当前开源版本：**1.16**（适配 Minecraft 1.21.11 / Meteor Client 1.21.11）

## 功能列表

* 亮度显示: 显示亮度, 按阈值显示不同颜色
* 存储查找增强: 给[存储透视]和[存储查找器]增加排除遗迹的选项
* 安全行走+: 在边缘时自动下蹲
* 实体列表: 可分维度显示实体列表
* 投影打印: 在grim无政府服务器中可用
* 村民交易: 自动村民交易
* 背包整理: 背包物品快捷操作（拖拽移动、同类移动、同类丢弃）
* 自动Kit: 自动装配Kit, 需要配合<简易仓库>使用。该功能由资深猎人dadou友情赞助开发。
* 自动分类: 提取有价格的物品, 需要配合<简易仓库>使用。该功能由资深猎人jiafog199友情赞助开发。
* 自动合成: 在工作台自动合成某些物品
* 自动头盔: 附近有猪灵时自动切换金头盔
* 自动签名: 自动写告示牌, 自适应玩家名和时间
* 自动贴画: 自动贴地图画, 由<hn2>友情赞助开发
* 自动附魔: 自动拿附魔书和装备按最优附魔顺序打造装备, 缺少经验时自动开启杀戮光环
* 袭击助手: 自动喝药, 自动开启杀戮光环
* 预览器: 盒子图标、盒子平铺
